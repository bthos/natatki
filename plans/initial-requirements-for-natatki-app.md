Product Requirements Document (PRD)

🎯 Цели

Создать приложение‑записную книжку для сбора идей и заметок.

Обеспечить автоматическую каталогизацию и дополнение описаний с помощью GitHub AI models.

Интегрировать идеи с существующими репозиториями пользователя.

Генерировать планы изменений в формате Markdown для target‑репозиториев.

Обеспечить полноценную работу на мобильных устройствах (iOS, Android).

📒 Уровень 1: Базовый функционал

Сбор идей/заметок

Создание заметок (текст, теги, категории).

Сохранение заметок в приватный GitHub репозиторий.

Каталогизация

Автоматическая категоризация заметок.

Дополнение описаний заметок с помощью GitHub AI models.

Мобильная поддержка

Запуск на iOS и Android.

Офлайн‑режим: заметки сохраняются локально и синхронизируются при подключении.

Быстрый ввод заметок (виджет, быстрый доступ).

Возможность прикреплять фото/аудио заметки.

📂 Уровень 2: Интеграция с другими репозиториями

Анализ существующих репозиториев

Сканирование README, issues, src/docs.

Определение тематики и целей.

Сопоставление новой идеи

Предложения по применению заметки в существующих проектах.

Рекомендация создать новый репозиторий при необходимости.

Мобильная поддержка

Просмотр списка репозиториев и анализа.

Push‑уведомления о рекомендациях.

Запуск анализа вручную с телефона.

📝 Уровень 3: План применения изменений

Генерация плана

Создание Markdown файла (plans/<note_id>.md).

Содержимое: цель изменений, шаги, рекомендации.

Автоматизация

Коммит плана в target‑репозиторий.

Возможность открыть Pull Request.

Мобильная поддержка

Просмотр и редактирование плана.

Уведомления о статусе PR.

Интеграция с GitHub Mobile.

🛠️ Технические компоненты

Frontend

Web‑версия.

Мобильные клиенты (React Native / Flutter).

Backend

API для работы с GitHub.

Модуль AI (GitHub Copilot Models).

Хранилище метаданных.

Интеграции

GitHub OAuth.

GitHub Actions.

Push‑уведомления (Firebase Cloud Messaging / APNs).
