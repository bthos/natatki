# Changelog

## 0.1.0 (2026-01-05)

### Added
- React Native mobile app (iOS/Android)
- Offline-first storage using WatermelonDB
- Notes list and edit screens
- Sync service with GitHub backend
- Secure token storage using react-native-keychain
- Network status monitoring
- Basic UI for note management

### Technical Details
- WatermelonDB with SQLite adapter
- React Navigation for routing
- Axios for API calls
- Conditional sync based on network status
- Local-first architecture
